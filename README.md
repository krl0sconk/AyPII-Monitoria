# AyPII-Monitoria

Material de apoyo para la monitoria de **Algoritmia y Programación II** (IST 2089),
prof. Daladier Jabba M. — Universidad del Norte.

Organizado por tema oficial del curso, cada uno con `pseudocodigo/` (sintaxis del
Manual de Informática II, unificada — ver `00_Recursos/Convenciones_Pseudocodigo.md`)
y `java/` (implementación equivalente, compilada y probada).

## Estructura

- `00_Recursos/` — convenciones de sintaxis
- `01_Vectores/` — conceptos, inserción, borrado, burbuja
- `02_Matrices/` — conceptos, **transpuesta**, burbuja, operaciones
- `03_Cadenas/` — operaciones básicas, palíndromo, `Cadenas.java` (tabla de
  equivalencias pseudocódigo↔Java) y menú interactivo
- `04_Procedimientos/` — subrutinas vs. funciones, ejercicio integrador
- `05_Recursividad/` — método de las dos preguntas, factorial/potencia/fibonacci,
  y `FuncRec.java`/`FuncNoRec.java` (comparación recursivo vs. iterativo,
  tomado del repo de la monitora anterior — el mejor recurso para explicar
  eficiencia)
- `06_Memoria/` — pilas, colas, cola circular, listas enlazadas (no había
  ningún material de este tema)
- `99_Parciales/` — espacio para parciales resueltos
